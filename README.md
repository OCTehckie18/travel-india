# Explore India

Explore India is a responsive static travel website that showcases memorable destinations across India, including the Taj Mahal, Kerala, and Goa.

## Features

- Hero section introducing India travel
- Featured destination cards
- Responsive desktop and mobile layout
- Navigation links for exploring the site
- Interactive “Start exploring” button
- Travel-focused visual design using local images

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Project structure

- index.html — main webpage
- css/style.css — layout, colors, typography, and responsive styles
- scripts/script.js — page interactions
- images/ — destination images
- docs/ — assignment and team tasksheet

## How to run

Open index.html directly in a browser.

For a local development server, run one of the following commands from the project folder:

    python -m http.server 8000

Then open http://localhost:8000 in your browser.

- main — stable final version

Team members create feature branches, commit their changes, push them to GitHub, and open Pull Requests into development. Changes are reviewed before merging. The final development branch is reviewed and merged into main.
